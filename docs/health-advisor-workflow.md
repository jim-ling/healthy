# 健康顾问与科普视频工作流

## 一次咨询的输出格式

1. 先判断问题属于健康管理、常见症状、用药/补充剂，还是需要尽快就医。
2. 给出检索到的事实、证据等级、适用人群和主要风险。
3. 明确哪些内容只是传统用途、动物/细胞研究或观察性关联，不能写成“有效”。
4. 给出可执行但低风险的下一步，以及需要问医生的情况。
5. 保留原始文件、记录 ID、抓取日期和来源链接。

## 视频脚本的固定结构

- 开头：具体问题和适用边界。
- 中段：目前人体研究/指南实际支持什么。
- 风险：禁忌、相互作用、特殊人群和不应延误的就医信号。
- 结尾：一句不夸大的结论、来源和更新时间。

“抗衰”“年轻化”“排毒”“提高免疫力”等词必须拆成可测结果，例如睡眠时长、跌倒风险、血压、血糖、疼痛评分或治疗副作用；不能把营销词直接当医学结局。

## 持续更新

当前本地索引由 `tools/build_index.py` 从 `phatxm/meddata` 重建。新增或更新 CSV、TSV、JSON、Markdown 后重新运行即可；索引保存文件哈希，后续可据此扩展增量更新。检索：

```bash
python3 tools/build_index.py
python3 tools/search_index.py 癌症 草药 相互作用
python3 tools/consult.py 癌症期间能不能吃补充剂
```

第一版是可追溯的 SQLite 全文 RAG 检索，不依赖云端模型或外部数据库。后续若需要语义检索，再在相同 `documents/chunks` 表上增加本地 embedding 和向量索引。

## 发布前核验

- 药品是否有监管批准或正式说明书？
- “有效”是否来自人体对照试验、系统综述或指南？
- 是否存在剂量、制剂、产地或人群差异？
- 是否有孕期、儿童、肝肾病、手术或合并用药风险？
- 是否把不良事件信号误写成发生率或因果关系？
- 是否给出原始来源、版本和更新时间？

癌症、外伤、持续或剧烈疼痛、神经功能异常等内容应优先做就医分流，不能用科普内容替代诊疗。
